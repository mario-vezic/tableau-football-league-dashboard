# ⚽ Slovenian First Football League Analytics Dashboard

## Overview

This project presents an interactive Tableau dashboard built using data from the **Slovenian First Football League** covering 19 seasons (2005/06–2023/24).

The dashboard combines league statistics, club performance, betting market analysis, and machine learning generated betting odds into a business intelligence solution designed for interactive exploration.

The project demonstrates how Tableau can be used to transform complex football and betting datasets into intuitive visual dashboards that support data-driven decision making.

This repository represents the visualization stage of a larger football betting analytics portfolio developed using Python, PostgreSQL, and Tableau. <br>
<br>

## Project Objectives

The goals of this project were to:

* Visualize historical Slovenian First League data.
* Explore long-term league trends.
* Analyse club performance interactively.
* Compare machine learning generated betting odds with bookmaker odds.
* Present betting market behaviour through interactive dashboards.
* Create an intuitive business intelligence solution for sports analytics. <br>
<br>

## Dataset

The analysis uses betting odds generated by a machine learning model together with market odds collected from **1XBet** and **William Hill** for matches in the **Slovenian First Football League**.

Generated betting odds produced by the accompanying Machine Learning project together with bookmaker odds from:

* My Model
* 1XBet
* William Hill

The profitability metrics displayed in Dashboard 4 are based on SQL analytical views created in the accompanying PostgreSQL project. <br>

## Dashboard Overview

### Dashboard 1 – Slovenian First League Overview

This dashboard provides a high-level overview of the Slovenian First Football League across all nineteen seasons.

**Features**:
* League KPIs
* Match outcome distribution
* Goals trend by season
* Goal distribution
* Market value trend
* Historical league performance

**Business Questions**:
* How has goal scoring evolved over time?
* Which match outcome is most common?
* How has league market value changed?
* What long-term trends exist within the league?

### Dashboard 2 – Team Performance & Club Intelligence

An interactive team analysis dashboard allowing users to select any club and explore its historical performance.

**Features**:
* Team selector
* Performance KPIs
* Goals scored vs goals conceded
* Home vs away performance
* Match outcome analysis
* Market value evolution
* Fair play trend

**Business Questions**:
* Which teams perform best over time?
* How do clubs compare at home versus away?
* How has club market value evolved?
* How does fair play relate to team performance?

### Dashboard 3 – Betting Market Analysis

This dashboard compares machine learning generated betting odds with bookmaker odds.

Interactive filtering enables users to analyse individual bookmakers independently.

**Features**:
* Average odds comparison
* Odds heatmap
* Odds distribution
* Winning vs losing bets
* Implied probability comparison
* Interactive bookmaker selection

**Business Questions**:
* How do generated odds compare with bookmakers?
* Which bookmaker offers higher odds?
* How are betting odds distributed?
* How do winning bets differ from losing bets?
* Interactive Example

Selecting only **My Odds** updates every visualization to focus exclusively on the machine learning model.

### Dashboard 4 – Betting Model vs Market Analysis

The final dashboard combines the SQL profitability analysis with the machine learning model to evaluate betting performance against the market.

**Features**:
* Model probability vs market probability
* Odds disagreement distribution
* Total profit by bet type
* Profitability heatmap
* Market category comparison
* Interactive filtering

**Business Questions**:
* Where does the model disagree most with bookmakers?
* Which market categories are most profitable?
* Which bet types generate the best returns?
* How does betting performance vary across market segments?

## Dashboard Features

## Key Insights

The dashboard demonstrates that:

Tableau effectively transforms large football datasets into intuitive visual stories. <br>
Interactive dashboards reveal long-term league trends more clearly than static reports. <br>
Machine learning generated betting odds can be compared visually against bookmaker markets. <br>
SQL profitability metrics integrate naturally into business intelligence dashboards. <br>
Sports analytics benefits from combining predictive modelling with interactive visualization. <br>
